README WEBSITE SMA ALTIORA
==========================

Nama Website : SMA Altiora
Slogan       : Rise Higher, Dream Further
Tema         : Modern, akademis, inspiratif, dan responsif

DESKRIPSI
---------
Website SMA Altiora merupakan website profil sekolah yang menampilkan
informasi sekolah, program akademik, guru dan staf, ekstrakurikuler,
fasilitas, berita terbaru, galeri kegiatan, dan informasi kontak.

Website dibuat menggunakan:
- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons
- Google Fonts
- JavaScript Bootstrap Bundle

CATATAN PENGGUNAAN GAMBAR
-------------------------
1. Seluruh gambar digunakan untuk kebutuhan website SMA Altiora.
2. Link sumber gambar dicantumkan sebagai dokumentasi dan atribusi aset.
3. Setiap gambar pada index.html memiliki atribut alt.
4. Gambar disimpan di dalam folder images.
5. Nama file pada README ini mengikuti nama file yang digunakan pada
   index.html.
6. Beberapa gambar digunakan pada lebih dari satu bagian website.
   Contohnya, gambar prestasi digunakan pada hero, berita, dan galeri.
7. Gambar ditampilkan menggunakan desain responsif dengan bantuan Bootstrap
   dan CSS.
8. Logo sekolah tidak berasal dari Pexels.
